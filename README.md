## 문제 정리

사용자는 자동차의 이름과 대수, 시도 횟수를 설정할 수 있다.

주어진 횟수 동안 자동차는 전진하거나 멈춘다.

자동자의 전진 조건은 무작위 값이 4 이상이어야 한다.

우승자는 한 명 이상일 수 있다.

사용자가 잘못된 문자열을 입력하면 메시지가 전달되는 동시에 오류가 발생해 프로그램을 종료시킨다.

## 개발

### 애플리케이션 흐름

**성공**

```
1. 사용자는 시합할 자동차 이름을 작성한다.
2. 자동차 이름을 검증한다.
3. 사용자는 시도할 횟수를 입력한다.
4. 시도 횟수를 검증한다.
5. 횟수 만큼 반복 실행한다.
6. 결과 형식을 출력한다.
```

**예외**

이름 잘못 입력한 경우

```
1. 사용자는 시합할 자동차 이름을 잘못 작성한다.
2. 자동차 이름을 검증한다.
3. 메시지를 출력하고 오류를 던지는 동시에 프로그램은 종료된다.
```

횟수 잘못 입력한 경우

```
1. 사용자는 시합할 자동차 이름을 작성한다.
2. 자동차 이름을 검증한다.
3. 사용자는 시도할 횟수를 잘못 입력한다.
4. 시도 횟수를 검증한다.
5. 메시지를 출력하고 오류를 던지는 동시에 프로그램은 종료된다.
```

`시도 횟수 검증`

### 예외 조건

예외조건은 계속 추가한다.

**자동차 이름 검증**

1. 입력하지 않은 경우

2. 5자 이하가 아닌 경우

**시도 횟수 검증**

1. 입력하지 않은 경우

### 주의사항

1. 이전의 실수를 반복하지 않는다.

2. 1주 차 공통 피드백을 따른다.

3. 들여쓰기 깊이가 3이 넘지 않도록 구현한다.

4. 3항 연산자를 사용하지 않는다.

5. 최대한 함수를 작게 만든다.

6. 기능 단위 테스트를 실시한다.
