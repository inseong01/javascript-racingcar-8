# javascript-racingcar-precourse

## 공통 예외처리

**출력 형식**

`[ERROR]`로 시작하는 메시지 출력

**재입력 방식**

예외를 발생시킨 후 애플리케이션 종료

## 흐름

```
경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
pobi,woni

시도할 횟수는 몇 회인가요?
1

실행 결과
pobi : -
woni :

최종 우승자 : pobi
```

## 기능

1. 입력 및 유효성 검사

   1. 자동차 입력

      - 쉼표(`,`)를 기준으로 구분하여 입력
      - 구분자가 , 아닌 경우
      - 이름이 5글자 초과인 경우
      - 공백인 경우
      - 이름이 중복되는 경우

   2. 시도 횟수 입력
      - 숫자 아닌 경우
      - 음수인 경우
      - 0인 경우
      - 공백인 경우

2. 핵심 로직

   1. 자동차(이름)

      - 이름 반환
      - 전진 거리 숫자 반환
      - 전진하기
        - 4이상 전진, 그외 정지

   2. 주사위

      - 난수 반환 (0~9)

   3. 심판(횟수)

      - 경기 생성
      - 승자 판별

3. 결과 출력

   1. 자동차 전진 거리 출력

      - `-`으로 표시
      - `이름 : ---`

   2. 우승자 출력

      - `최종 우승자: 이름`
